# 19 · UI 原型

客户端界面的完整线框。**左侧竖向标签列 + 右侧单终端**，v1 不分屏。

设计原则：

1. **终端是主体**，其余都是围绕它的浮层
2. **状态可见**：谁在线、哪个终端在后台有输出、连接质量如何，一眼看到
3. **断线用横幅不用弹窗**：断线是常态，弹窗会打断正在做的事
4. **每个功能至少两个入口**：快捷键 + 可见按钮

## 4 · 主工作区（左侧标签列 + 右侧单终端）

```

│   ● ● ●   remote-pty · 已连接 MacBook Pro           ⌘K   ⌘?   ⚙              │
```

## 7 · 断线重连

```
┌──────────────────────────────────────────────────────────────────────────────┐
│   ● ● ●   remote-pty · 正在重连…                    ⌘K   ⌘?   ⚙              │
├──────────────────────────────────────────────────────────────────────────────┤
│  ┃ ⇅  连接中断 · 第 2 次重试 · 3 秒后再次尝试      [ 立即重试 ]              │
├───────────────┬──────────────────────────────────────────────────────────────┤
│  会话         │  ~/code $ npm test                                           │
│               │  ...                                                         │
│  ○ MacBook    │  [连接恢复后，断线期间的输出会补在这里]                      │
│    Pro        │                                                              │
│    ○ 离线     │  ~/code $                                                    │
│               │                                                              │
│ ▸ zsh         │                                                              │
│ ▸ vim         │                                                              │
│ ▸ htop        │                                                              │
├───────────────┴──────────────────────────────────────────────────────────────┤
│  ○ 重连中…   —    zsh  80×24                   12:05:02   ⌘/   [?]           │
└──────────────────────────────────────────────────────────────────────────────┘
```

横幅不遮挡终端内容、不弹窗——断线是常态而非异常，弹窗会打断正在进行的操作。

## 12 · 视觉与交互约定

| 用途 | 色值 |
| --- | --- |
| 窗口背景 / 左侧列表 / 标题栏 | `#1e1e1e` / `#252526` / `#2d2d2d` |
| 前景 / 次要文本 | `#cccccc` / `#8a8a8a` |
| 边框与分割线 | `#3c3c3c` |
| 强调（选中项） | `#4ec9b0` |
| 在线 / 重连 / 断开 | `#89d185` / `#cca700` / `#f14c4c` |

字号：UI 13px，终端 14px `fontWeight 300`。间距走 8pt 栅格。

布局尺寸：标题栏 28px、左侧列表 200px（可折叠）、状态栏 24px。

交互约定：

1. 破坏性操作才用模态框，且默认焦点在取消侧
2. 断线、重连一律用横幅
3. 状态栏永远显示连接质量，让用户对"卡不卡"有预期
4. 关闭有活动的终端必须二次确认
