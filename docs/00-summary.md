# 00 · 需求与设计总览

一页看完这个项目要做什么、怎么定的。细节见后续各篇。

---

## 1. 一句话

**在家用公司 Mac 的 CLI，不依赖 SSH，不装任何隧道二进制，云主机全程看不到内容。**

---

## 2. 四条约束（决定了方案形状）

| 约束 | 影响 |
| --- | --- |
| 公司 Mac 上 `frpc` 一启动就被杀 | 排除所有外部隧道程序（frp / chisel / tailscale / ttyd） |
| 两端都是 Mac（Intel + Apple Silicon） | 排除需要分架构编译的产物，用纯 Python |
| 两端都只能出站 443 | 不监听端口，只做主动连接 |
| 目标必须能用 `vim` / `htop` | 必须有真 PTY，不能是"执行命令回传输出" |

---

## 3. 最终形态

```
   家 Mac ═══ wss:443（密文）═══▶ 云主机 relay ═══ wss:443（密文）═══▶ 公司 Mac
   同构 peer                      在线表 + DIAL + 桥接                  同构 peer
   一份程序                        约 170 行                            一份程序
```

- **服务端**只做交换机：知道谁在线、把两条连接接上，然后变成纯字节管道
- **客户端**是同构节点：每台都能当宿主、都能当控制方
- **会话数据**（PTY、ring buffer、文件）全部在宿主机器上

---

## 4. 核心决策（12 条）

| # | 维度 | 决策 |
| --- | --- | --- |
| 1 | 拓扑 | **一对一**，两个节点一条桥（不做 mesh） |
| 2 | 建链 | **单向**：谁点击列表谁发起 |
| 3 | 使用 | **双向**：桥通了，各自都能开通道 |
| 4 | 服务端 | 在线表 + DIAL 信令 + 字节桥接，无业务数据 |
| 5 | 客户端 | **一份程序**，无 `--role` 参数，无安装包差异 |
| 6 | 连接 | **两条**：control 常驻（JSON）+ data 按需（二进制） |
| 7 | 通道 | `shell` / `file` / `forward`，channel id 高位表方向 |
| 8 | 加密 | **必选**：ECDH + 静态密钥签名；**密码可选**：混入 PSK 熵 |
| 9 | 身份 | `node_id = SHA256(公钥)[:8]`，首次连接 TOFU 确认指纹 |
| 10 | 权限 | 三层：ACL 白名单 + 方向判定 + PSK 验证 |
| 11 | 会话 | 宿主侧 broker，ring buffer 保输出，断线不杀 shell |
| 12 | 协议 | 二进制帧（8 字节头），data 载荷全程密文 |

---

## 5. 密码规则（v18 定下的，最容易记错）

```
   建链        不需要密码    ← 谁发起谁就能连
   正向控制    不需要密码    ← 我主动连你，你同意了，我能开 shell
   反向控制    需要密码      ← 你是被动方，不能反过来控制我
   反向开通道  需要人工确认  ← 密码是技术门槛，确认是人的门槛
```

| 谁想开 shell | ACL | 我是发起方 | PSK 已验证 | 结果 |
| --- | --- | --- | --- | --- |
| 发起方 → 被动方 | ✓ | ✓ | 任意 | 允许 |
| 被动方 → 发起方 | ✓ | ✗ | ✓ | 允许 |
| 被动方 → 发起方 | ✓ | ✗ | ✗ | 拒绝 `need_psk` |
| 任意方向 | ✗ | 任意 | 任意 | 拒绝 `denied` |

**密码不是门禁，是提权凭据。**

---

## 6. 数据在哪

| 数据 | 位置 | relay 可见 |
| --- | --- | --- |
| 终端内容、ring buffer、PTY | 宿主内存 | 否（密文） |
| 文件、私钥、ACL | 各自本机 | 否 |
| 谁在线、哪两条连接配对 | relay 内存 | 是（重启即丢） |

---

## 7. 规模

| 组件 | 规模 |
| --- | --- |
| relay | ~170 行 |
| peer（建连 + 通道 + 会话） | ~500 行 |
| web 终端（xterm.js） | 单文件 |
| 部署 | nginx + systemd 八行；无数据库、无密钥配置 |
| 首版工期 | 5–7 个工作日 |

---

## 8. 明确不做

多 bridge（同时连多台）、会话迁移、WebRTC 打洞、共享终端（多人看同一会话）、图形界面转发、移动端 App。
