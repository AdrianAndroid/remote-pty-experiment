# 01 · 背景与方案演进

记录从最初需求到最终定型的完整决策路径，保留每个方案被否掉的原因，避免以后重复踩坑。

---

## 1. 原始需求

> 我的电脑和公司的电脑是异地。想在家里使用公司电脑的 CLI。能不能都连上服务器的某个服务，达到这个目的。

拆解成三条硬需求：

1. **异地**：两台机器不在同一内网，没有公网 IP 直连条件。
2. **可用中转**：存在一台两端都能访问的云主机。
3. **目标能力是交互式 CLI**：不是文件同步、不是远程桌面，是在家能敲公司机器上的 shell。

---

## 2. 方案演进时间线

```
① SSH 反向隧道
      ↓  （可行，但担心出站 ssh 被审计 / 想更彻底）
② SSH over 443 伪装
      ↓  （可行，但仍是 ssh 协议特征）
③ frp / chisel / tailscale
      ↓  （✗ frp 实测被终端安全软件 kill，进程级拦截）
④ webhook 轮询任务
      ↓  （可行，但只能跑一次性命令，无 tty、无交互、cd 不保持）
⑤ WebSocket 自研中继 + PTY   ← 最终选定
```

## 3. 各方案评估

### 3.1 SSH 反向隧道（`ssh -R`）

公司 Mac 主动连云主机，把本地 22 映射到云主机回环端口：

```bash
ssh -N -R 127.0.0.1:2222:127.0.0.1:22 user@cloud -p 443 \
    -o ServerAliveInterval=30 -o ServerAliveCountMax=3
```

家 Mac 先连云主机，再从云主机内部 `ssh 127.0.0.1 -p 2222`。

**优点**：零开发量，`ssh` 是系统自带，进程特征弱。
**缺点**：
- 本质仍是 SSH 协议出站，部分企业网关/EDR 对 `-R` 反向转发有专门检测。
- 公司 Mac 需要开启 sshd（监听本地 22），引入监听端口，不符合"两端零监听"的目标。
- 断线不自动重连，Windows 上还得配 autossh / 计划任务（本场景两边是 Mac，问题小一些）。

**结论**：作为兜底方案保留，不作为主线。

### 3.2 frp / chisel / tailscale

**实测结论：`frpc` 一启动就被 kill。** 说明拦截发生在**进程与二进制特征层**，不是网络层。同类的 `chisel`、`nps/npc`、`tailscale`、`zerotier`、`ttyd`、`gotty` 都是特征明显的独立模块化程序，属于同一风险等级，全部不采用。

这条结论决定了后续选型的核心原则：

> **不使用任何外部下载的、有公开特征的隧道类二进制。**

### 3.3 webhook 轮询任务队列

家端 POST 命令到云主机 → 公司端 Agent 定时 GET 拉取 → 执行 → POST 回传 stdout。

**优点**：全程只有 `curl` / `Invoke-WebRequest`，无隧道程序、无长连接。
**无法接受的缺点**：
- 没有 tty：`vim`、`htop`、`sudo` 输密码全部不可用。
- 无会话：每条命令是独立进程，`cd` 不保持。
- 天然异步：延迟不低于轮询间隔。

**结论**：只适合批量任务，不适合本项目目标。但其"双向 HTTP + 无监听端口"的思路被继承下来。

### 3.4 WebSocket 中继 + 真实 PTY（选定）

两端都是 wss 出站长连接，云主机做字节桥接，Agent 端 `forkpty` 拉起登录 shell。

**为什么是它**：
1. **零监听端口**——公司 Mac 不开 sshd、不开任何端口，只有出站 TCP。
2. **流量即网页流量**——443 上的 `Upgrade: websocket`，与在线 IDE、聊天室、协同文档无异。
3. **进程是脚本解释器**——`python3`，不是特征化二进制。
4. **协议模型等价 SSH**——本地 tty ↔ 字节流 ↔ 远端 pty，所以 `vim`/`htop` 天然可用。

**代价**：需要自己实现 resize 同步、断线重连、心跳、鉴权。

## 5. 关键设计原则（后续所有决策的依据）

1. **零监听**：两端只出站，不监听任何端口。
2. **零陌生二进制**：不引入任何需要下载运行的隧道程序；只用脚本与系统自带组件。
3. **协议等价 SSH**：必须分配真实 PTY，而不是"执行命令回传输出"。
4. **控制帧与数据帧分离**：终端字节流走 `data`，元信息（resize / 剪贴板）走独立控制帧，互不污染。
5. **显式授权**：远程控制办公设备存在合规风险，代码层留 `AUTHORIZED=1` 强制确认位。
