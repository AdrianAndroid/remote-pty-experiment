# 04 · 能力边界与验收标准

回答一个核心问题：**这套东西用起来是不是真的和坐在公司那台 Mac 前面一样？**

结论：**架构上和 SSH 等价，绝大部分 CLI 一致；但有 5 处需要额外实现，2 处天然做不到。**

## 2. 需要额外实现的 5 项

### 2.1 窗口尺寸同步（必须做，否则 vim 必花屏）

不做时现象：家端把浏览器窗口拉宽 → 远端仍是 120 列 → `vim` 里 `~` 波浪线位置错乱、`htop` 表格挤压。

实现链路：

```
xterm fitAddon.onResize
  → debounce 80ms
  → ws.send({type:"resize", cols, rows})
  → relay 转发
  → agent: pty.setwinsize(rows, cols)
  → 内核 signal SIGWINCH → vim 重绘
```

验收：`vim` 里 `:set columns?` 家端拖拽后数值跟随变化；`htop` 右侧无截断。

### 2.2 作业控制（`ctrl+z` / `fg` / `bg`）

`ptyprocess` 库对作业控制支持较弱，`ctrl+z` 可能直接让 shell 卡死。

两条路：
- **A（推荐）**：不用 `ptyprocess`，直接 `os.forkpty()` 原生实现，作业控制完整。
- B：只保证 `ctrl+c`，`ctrl+z` 明确不承诺，文档写清。

验收：`sleep 100` → `ctrl+z` → `jobs` 显示 Stopped → `fg` 能恢复。

### 2.3 浏览器组合键劫持

网页终端下，这些键会被浏览器或系统先吃掉，到不了远端：

| 组合键 | 冲突 | 处理 |
| --- | --- | --- |
| `ctrl+w` | 关闭标签页 | `attachCustomKeyEventHandler` 拦截，`preventDefault` |
| `ctrl+t` | 新建标签页 | 同上 |
| `ctrl+n` | 新建窗口 | 同上 |
| `ctrl+shift+c/v` | 浏览器复制粘贴 | 转成 clipboard 控制帧 |

不处理时现象：`vim` 里按 `ctrl+w` 会直接关掉整个页面，以为是 bug。

验收：网页端 `vim` 里 `ctrl+w` + `s` 分屏正常，标签页不关闭。

本地 raw 客户端（`term_mac.py`）无此问题。

### 2.4 剪贴板互通（v2）

默认不通：远端写的是文本字节，不会进入家端 Mac 的系统剪贴板。

- 家 → 公司：普通粘贴走 `data` 帧即可（等价于逐字输入）
- 公司 → 家：需要 `clipboard` 控制帧，agent 端触发 `pbpaste`，或支持 OSC 52 转义序列

验收：公司 Mac 上 `cat 某文件` 后，家端能一键复制全部输出到本地剪贴板。

### 2.5 会话保持（v2）

v1 断线重连 = 新 shell，目录和正在跑的程序全丢。

三种可选：
1. 用 `tmux`：agent 端 spawn `tmux new -A -s main`，断线重连自动 attach 回原会话。**成本最低，推荐**。
2. agent 侧保留 PTY 进程，仅重连 ws。
3. 完整会话持久化（复杂度高，不做）。

## 3. 天然做不到的 2 项

| 项 | 原因 | 替代 |
| --- | --- | --- |
| 本地终端特性（分屏、热键、主题、字体） | 属于家端客户端渲染层，与远端无关 | 在家端 iTerm / 浏览器里自行配置 |
| 图形界面、音频、摄像头 | 方案只搬运 tty 字符流 | 需要图形层就走 VNC / 屏幕共享（另案） |

- [ ] `htop` 正常刷新，`q` 退出；拖拽窗口后表格自适应

- [ ] Tab 补全、上下键历史、`ctrl+r` 搜索正常

- [ ] 中文输出（`echo 中文测试`）无乱码
- [ ] 断开公司 Mac 网络 5 分钟再恢复，agent 自动重连成功，无需人工干预

## 5. 性能预期

| 指标 | 目标 | 备注 |
| --- | --- | --- |
| 按键到回显延迟 | < 200 ms | 取决于家→云、云→公司两段 RTT 之和 |
| `vim` 大文件滚动 | 无卡顿 | 单帧 ≤ 64 KB，超出切分 |
| `cat` 大文件 | 不丢字节 | base64 透传，无文本解码 |
| 内存占用 | agent < 60 MB | asyncio + 单 PTY |
| 空闲带宽 | ≈ 0 | 无数据时不发帧，仅 20s 心跳 |
